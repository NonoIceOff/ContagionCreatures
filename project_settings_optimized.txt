## ========================================
## OPTIMISATIONS SCÈNE PAR SCÈNE
## ========================================

# TileMap:
# - Utiliser des layers séparés pour collisions
# - Activer "Cell Quadrant Size" approprié (16 pour tiles 16x16)
# - Utiliser Y-sort pour les objets qui passent derrière/devant

# Camera2D:
# - Activer "Smoothing" avec valeur 5-10
# - Ajuster "Zoom" au lieu de changer la résolution
# - Utiliser "Limit" pour éviter de voir hors de la map

# AnimatedSprite2D:
# - Mettre "Speed Scale" à 1.0 par défaut
# - Utiliser des sprite sheets au lieu de frames individuelles
# - Activer "Centered" pour simplifier les calculs

# CharacterBody2D:
# - Utiliser "Motion Mode: Grounded" pour personnages au sol
# - Ajuster "Max Slides" (par défaut 4, essayer 6 pour mouvements fluides)
# - Activer "Floor Snap Length" pour meilleure adhérence au sol

# ParticleProcessMaterial:
# - Limiter "Amount" à 32-64 pour effets courants
# - Réduire "Lifetime" au minimum nécessaire
# - Utiliser "One Shot" quand possible au lieu de "Emitting" continu
